# Nyx - Backend

Backend do aplicativo Nyx, uma aplicação de IA.

## Estrutura

- `app.py` - Aplicação principal Flask/FastAPI
- `models/` - Modelos de dados
- `routes/` - Rotas da API
- `services/` - Serviços de IA e lógica de negócio
- `config.py` - Configurações do ambiente

## Instalação

```bash
pip install -r requirements.txt
```

## Execução

```bash
python app.py
```

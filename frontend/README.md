# Nyx - Frontend

Frontend do aplicativo Nyx, uma aplicação de IA.

## Tecnologias

- React 18
- Vite
- TypeScript
- TailwindCSS

## Estrutura

- `src/components/` - Componentes reutilizáveis
- `src/pages/` - Páginas da aplicação
- `src/services/` - Serviços de API
- `src/hooks/` - Hooks customizados
- `src/context/` - Contextos React

## Instalação

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

## Build

```bash
npm run build
```
